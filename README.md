# 📖 Overview

CareerNova AI is an **AI-powered Career Intelligence Platform** designed to help students and professionals become interview-ready using Large Language Models (LLMs).

Unlike traditional resume analyzers, CareerNova AI uses a **Multi-Agent AI Architecture** where specialized AI agents collaborate to provide intelligent career guidance.

The platform analyzes resumes, evaluates ATS compatibility, generates career roadmaps, conducts mock interviews, and answers career-related questions using state-of-the-art LLMs powered by **Groq + Llama 3.3**.

# 🧠 AI Architecture

CareerNova AI follows a **Multi-Agent Architecture**.

```
                User
                  │
                  ▼
        AI Command Center
                  │
                  ▼
          Intent Router
                  │
 ┌──────────┬──────────┬──────────┬──────────┐
 ▼          ▼          ▼          ▼
Resume     ATS      Career      Chat
 Agent     Agent     Agent      Agent
 │          │          │          │
 └──────────┴──────────┴──────────┘
                  │
                  ▼
            Groq LLM
          (Llama 3.3)
```

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/CareerNova-AI.git
```

Go inside

```bash
cd CareerNova-AI
```

Create virtual environment

```bash
python -m venv venv
```

Activate

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create `.env`

```env
GROQ_API_KEY=your_groq_api_key
```

Run

```bash
streamlit run app.py
```
